# CRA Watch, 3-minute demo video (script and shot list)

Recording: desktop 1440 wide, light office scene, the console at http://localhost:8000. Voice: Bernard. Screen: Tim.
Timing is tight; cut narration, not steps.

| Time | Screen | Narration |
|---|---|---|
| 0:00 | Title card: CRA Watch. Then the console, empty state: "Pre-incident checks", Sentinel register with HIGH flags on #42, #43, #45. | A fintech ships payment software in the EU. Its AI coding agent used a library called fast-pay-utils. Every test passed. Under the Cyber Resilience Act, a compromised library in your product is a severe incident, and you have 24 hours to warn ENISA. This is CRA Watch. |
| 0:25 | Click commit #42 in the Sentinel register. Flag detail: hidden Unicode-tag instruction in the README the agent read, CWE-506, classified by Nemotron Nano. Scroll the decoded hidden text. | Before any CVE exists, Sentinel reads what each agent commit read and wrote. In session 42 the package README carried an invisible instruction. Nemotron Nano classified it high risk, with the evidence quoted. Most tools wait for the CVE. This one already flagged it. |
| 0:50 | Click "Poll feeds". Journal: Tavily reads the vendor bulletin; "Advisory matched watched dependency fast-pay-utils". The incident record appears, clock starts at 23:59:59. | The advisory drops. The monitor, a Nebius Serverless Job, polls the feeds through Tavily. It matches fast-pay-utils, opens the incident, and the 24-hour clock starts. |
| 1:05 | Pipeline steps fill in live: Trace (Origit taint: 7 commits, sessions 42 to 49, rollback commit), Read (Tavily extract), Triage (Nemotron Nano: HIGH, 8.2, Article 14 applies). | Origit's provenance records answer in milliseconds: seven commits across seven sessions, eight files, the approver, and the last clean commit to roll back to. Tavily reads the full advisory. Nemotron Nano, the fast tier, classifies it: high, payment data at risk, Article 14(5)(b) applies. |
| 1:35 | Context step: 5 sources on the vulnerability class, 5 on CRA Article 14. Scroll "Sources read". Draft step completes. | Tavily then pulls what the drafter needs: analysis of this class of npm supply-chain attack, and the CRA Article 14 guidance from the Commission and ENISA. All of it goes to Nemotron 3 Ultra on Nebius Token Factory. Unpatched code never leaves private inference. |
| 2:00 | The draft sheet: scroll the early warning. Point at placeholders for member states and contact. Affected components table with Sentinel flags. | The early warning: manufacturer and product, awareness time and deadlines, nature of the incident, affected commits and sessions, the rollback, placeholders for what the evidence does not contain. Every line traces to a commit, a source, or a model call. |
| 2:25 | Click "Approve and file". Stamp presses on, clock turns green: filed 00:0X:XX after awareness. Open the run ledger: Nemotron calls, tokens, Tavily calls. | A person approves. The clock stops. Eleven minutes of a 24-hour window. Here is everything that ran: which Nemotron tier, how many tokens, which Tavily calls. |
| 2:45 | README on GitHub, then title card with the stack logos. | Nebius Serverless Jobs and Endpoints, Token Factory, Nemotron Nano and Ultra, Tavily, and Origit, our open-source provenance layer. CRA Watch: from CVE to filed early warning before the clock moves. |
